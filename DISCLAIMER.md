# Disclaimer & Trademark Notice

## Unofficial and independent

**warp-gui** is an **unofficial, independent, community-built** graphical
front-end for the Cloudflare WARP command-line client (`warp-cli`) on Linux.

It is **not** affiliated with, authorized by, endorsed by, sponsored by, or in
any way officially connected to **Cloudflare, Inc.** Cloudflare does not
currently ship an official WARP GUI for Linux; this project exists purely to
make the *existing, official* `warp-cli` easier to use for personal Linux
desktops. It is provided by the community, for the community.

## It does not bundle or redistribute Cloudflare software

warp-gui contains **none** of Cloudflare's software, source code, or brand
assets. It does not download, install, modify, patch, or redistribute the
Cloudflare WARP client.

To function, warp-gui requires that **you** have already installed the official
Cloudflare WARP client (the `cloudflare-warp` package) yourself, obtained
directly from Cloudflare through their official channels. warp-gui simply calls
the `warp-cli` program that ships with that client — exactly the same commands a
user would type in a terminal — and displays the results. If the official
client is not installed, warp-gui does nothing.
